# SalesIQ — Analytics Dashboard

A self-contained sales analytics dashboard powered by Supabase.

**Live:** [chaudharydev798-hue.github.io/Sales_Dashboard](https://chaudharydev798-hue.github.io/Sales_Dashboard/)

---

## Features

**Dashboard**
- KPI cards for total revenue, order count, average order value, unique customers, and total discounts
- Revenue, orders, and AOV trend line chart with tab switching
- Order status distribution as a doughnut chart
- Daily sales bar chart
- Top 5 sales rep leaderboard

**Orders**
- Full orders table with gross, discount, and net columns
- Search and filter by status
- Sortable columns, paginated at 12 rows
- Click any row to open a detailed order modal

**Customers**
- Ranked by lifetime revenue
- Shows order count, average order value, and last order date
- Searchable

**Sales Reps**
- Ranked by revenue with order count, AOV, and revenue share progress bar

**Reports**
- One-click CSV export for orders, customers, and rep performance
- Database summary showing totals across all time

**General**
- Dark theme
- Date range filter (7, 30, 90 days, or all time)
- Fully responsive — works on mobile
- No install, no build step — single HTML file
